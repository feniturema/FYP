## 1. 目标与非目标

**问题**：简历第四条写了 “GPT-4o Vision listing pipeline”，但仓库里没有这个功能。

| | 实施前 | 实施后 |
| --- | --- | --- |
| 二手物品上架 | 用户手动填写所有字段 | 上传图片后，可以点击“AI 生成草稿”，得到标题、类目、成色、建议价格和描述的**建议值** |
| 发布 | 由用户提交 | 不变。AI **只生成草稿**，不自动发布，不自动保存，也不会覆盖用户已经手工填写的字段 |
| 模型 | 无 | OpenAI 视觉模型（默认 `gpt-4o`），由我们手工构建，bean 名称为 `visionChatModel`，与助手使用的 DeepSeek 模型互不干扰 |

**非目标**：

- 自动发布；
- 批量处理；
- 把外部 URL 直接交给模型（只接受本站上传的文件）；
- 新增数据库迁移；
- 修改助手相关代码。

## 6. 实现契约

### 6.1 HTTP

请求：`POST /api/items/draft-from-image`，需要 JWT。

```java
record DraftFromImageRequest(@NotBlank @Size(max = 64) String imageUrl) {}
record ListingDraft(String title,            // 1..80 chars
                    String category,         // CatalogCategory.name()
                    String condition,        // NEW | LIKE_NEW | USED
                    BigDecimal suggestedPrice, // 0.50..100000.00, scale 2
                    String description,      // 0..1000 chars
                    String model)            // e.g. "gpt-4o", for transparency
{}
```

| 情况 | HTTP | `code` |
| --- | --- | --- |
| 成功 | 200 | — |
| 未认证 | 403（与现有接口一致） | — |
| `imageUrl` 格式不合法、路径越界、是符号链接 | 400 | `INVALID_IMAGE_URL` |
| 文件不存在 | 404 | `IMAGE_NOT_FOUND` |
| 真实的文件类型与扩展名不一致、是 GIF、文件超过 5 MB | 415 | `UNSUPPORTED_IMAGE` |
| 同一用户已有进行中的请求，或触发限流 | 429 | `TOO_MANY_REQUESTS` |
| 模型的输出无法解析，或校验之后没有任何可用字段 | 422 | `INVALID_MODEL_OUTPUT` |
| 没有配置 key，或 `VISION_ENABLED=false` | 503 | `VISION_NOT_CONFIGURED` |
| 上游返回错误，或熔断器打开 | 503 | `VISION_UNAVAILABLE` |
| 超时（30 s） | 504 | `VISION_TIMEOUT` |

错误 body 沿用 `GlobalExceptionHandler` 现有的格式，并新增一个 `code` 字段。

### 6.2 图片路径校验（`UploadedImageResolver.resolve(String imageUrl): ResolvedImage`）

1. 必须**完整**匹配 `^/uploads/([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})\.(jpg|png|webp|gif)$`，并且 `UUID.fromString(group1).toString().equals(group1)`（必须是规范的小写形式）。不匹配时返回 400。
   - 任何 `http:`、`https:`、`//`、`..`、`%2e`、反斜杠都不可能通过这个正则，所以**不会**把任意外部 URL 交给模型。
2. `Path base = Paths.get(uploadDir).toRealPath();`
3. `Path p = base.resolve(group1 + "." + ext).normalize();`；`!p.startsWith(base)` 时返回 400。
4. `Files.exists(p, NOFOLLOW_LINKS)` 为 false 时返回 404；`Files.isSymbolicLink(p)` 为 true 时返回 400；`!Files.isRegularFile(p, NOFOLLOW_LINKS)` 时返回 400。
5. `p.toRealPath().startsWith(base)` 必须成立，否则返回 400（防御父目录被替换成符号链接的情况）。
6. `Files.size(p) > 5 * 1024 * 1024` 时返回 415。
7. 读取文件头的魔数，判断真实格式：
   - JPEG：`FF D8 FF`；
   - PNG：`89 50 4E 47 0D 0A 1A 0A`；
   - WEBP：文件头 `RIFF`，并且第 8–11 个字节为 `WEBP`；
   - GIF：`GIF87a` / `GIF89a`。

   真实格式与扩展名不一致时返回 415。
8. **格式策略**：JPEG、PNG、WEBP 允许发送给模型；GIF 一律返回 415。原因是动图只会用到第一帧，而且项目不需要 GIF。上传 GIF 本身仍然允许，只是不能用来生成草稿。

### 6.3 `ListingDraftService.draft(long userId, String imageUrl): ListingDraft`

1. `holder.get()` 为空：返回 503 `VISION_NOT_CONFIGURED`。
2. 获取 `inFlightGuard`：已有进行中的请求时返回 429。在 `finally` 中释放。
3. 限流（Resilience4j）：
   - 全局实例 `vision-global`：每分钟 30 次；
   - 每用户实例：从 `RateLimiterRegistry` 中取名为 `vision-user-<userId>` 的实例，每分钟 5 次；
   - 用户实例的配置通过 `registry.rateLimiter(name, config)` 创建，实例数量由 Caffeine 缓存限制在 1000 个以内。

   被拒绝时返回 429。
4. 把文件读成 `byte[]`，构造 `new Media(MimeTypeUtils.parseMimeType(真实 MIME), new ByteArrayResource(bytes))`，以内联 base64 的方式发送，**不发送 URL**。
5. prompt 中：
   - 列出 10 个类目的名称和 3 种成色；
   - 要求只返回 JSON，字段与 `ListingDraft` 相同，`model` 字段除外；
   - 要求价格以 RM 为单位，并给出合理范围；
   - 写明“如果图片不是二手商品，所有字段返回 null”。
6. 调用 `ChatClient.builder(model).build().prompt().user(u -> u.text(PROMPT).media(media)).call().content()`，超时 30 s（`CompletableFuture.orTimeout`），外层加 `@CircuitBreaker(name="vision")`。
7. **对模型输出逐字段校验**：
   - `title`：trim 后长度为 1–80，否则置为 null；
   - `category`：用 `CatalogCategory.parse` 解析，失败则置为 null；
   - `condition`：必须属于 3 个枚举值之一，否则置为 null；
   - `suggestedPrice`：必须在 [0.50, 100000]，四舍五入到 2 位小数，否则置为 null；
   - `description`：截断到 1000 个字符。

   全部字段都为 null 时返回 422。
8. 记录 token 用量（INFO 日志：userId、模型、输入和输出的 token 数，**不记录**图片内容）。
9. **成本边界**：`maxTokens=400`；单张图片 ≤ 5 MB；每用户每分钟 5 次，全局每分钟 30 次。

### 6.4 `VisionModelHolder` 与启动

- `OPENAI_API_KEY` 为空，或 `VISION_ENABLED=false`：不创建任何模型对象，应用照常启动。
- 不依赖 `spring.ai.model.chat=openai` 这个自动配置（开启它会和助手的 provider 冲突）。
- OpenAI starter 带来的其他自动配置，由 P5b §6.1 中的 `spring.ai.model.*: none` 关闭。如果 P5b 没有选择 openai，本阶段必须在 yml 中加上这几项。`VisionStartupIT` 负责证明在没有 key 的情况下应用能够启动。

### 6.5 前端（`draftMerge.ts`）

```ts
export type DraftField = 'title' | 'category' | 'condition' | 'price' | 'description';
export function mergeDraft(form: FormState, draft: ListingDraft, touched: Set<DraftField>):
  { next: FormState; suggestions: Partial<Record<DraftField, string>> }
```

- 用户**手工改过**的字段（在 `touched` 中），或者当前不为空的字段：不覆盖，只放进 `suggestions`，由用户逐项点击“采用”。
- 空字段且没有被手工改过的：可以直接填入。
- 按钮在请求期间禁用（防止重复点击）。
- 组件卸载或者用户换了一张图时，`abort()` 当前请求。
- 结果面板上写明“AI 生成，仅供参考”。
- 用户必须自己点击原有的“发布”按钮，AI 不会触发提交。
